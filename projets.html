Mes projets

Voici les projets sur lesquels j'ai travaille, a l'ecole et de mon cote :

2eme annee

Module 114 - Codification du Morse

J'ai programme en C# un convertisseur qui traduit un mot ou une phrase en code Morse. Avant de coder, j'ai modelise l'algorithme, puis j'ai utilise un dictionnaire, des boucles et des conditions pour la conversion.

Module 129 - P_RES : reseau de la Commune de Riviera

En binome, on a concu le reseau local d'une commune fictive (3 batiments, environ 100 utilisateurs) : schema reseau, plan d'adressage IP avec des VLANs, un routeur par batiment avec du routage statique, et toute la configuration en ligne de commande dans Cisco Packet Tracer.

Module 141 - P_DB : activite pour les Portes ouvertes

J'ai prepare une activite ludique sur les bases de donnees pour les Portes ouvertes de l'ETML, avec SQL Server et une base de plus de 10 millions d'enregistrements, ainsi que les manuels d'installation et d'animation et une affiche.

1ere annee

Module 122 - PowerShell SysInfo Logger

En binome, j'ai developpe un script PowerShell qui recupere les informations d'un ordinateur local ou distant (nom, systeme, disque, RAM, programmes installes) grace a la base CIM, puis les enregistre dans un fichier log.

Module 123 - Services serveurs

J'ai installe et configure un Windows Server 2022 avec un client Windows 11 : DHCP, DNS, Active Directory, gestion des utilisateurs et des groupes, droits NTFS, partages et imprimantes.

Module 162 - P_DB Excel : temps d'ecran

J'ai recolte et analyse mes propres donnees sur le temps que je passe devant les ecrans (reseaux sociaux, jeux, travail...) dans Excel, puis je les ai presentees avec des graphiques dans un rapport.

Module 187 - Installation de postes de travail

J'ai installe et configure des machines virtuelles Windows 11 et Ubuntu.

Module 216 - Smarthome

Sur une maquette de maison connectee avec Arduino, j'ai imagine un scenario domotique et programme des capteurs et des actionneurs pour rendre la maison autonome.

Module 306 - HealthTrack

En equipe et avec la methode Scrum, j'ai cree une application AppSheet de suivi du bien-etre pour les etudiants (sport, alimentation, sommeil, hydratation). Au 2e sprint, on a ajoute des objectifs par semaine, des calculs automatiques et des indicateurs "atteint / non atteint".

Module 319 - Secret Code

J'ai programme en C# un jeu en mode console inspire du Mastermind : le joueur doit deviner un code secret de 4 chiffres en 10 essais maximum, avec plusieurs niveaux de difficulte et des indices en couleur.

P_OFFICE - Outils bureautiques

J'ai realise un portfolio digital dans Word (autobiographie, CV, plan de formation), un suivi de mes moyennes dans Excel avec un graphique de tendance, et un CV automatique anime dans PowerPoint. J'ai aussi appris a utiliser Outlook et To Do.

P_Remed_Appro - Infrastructure Proxmox

En classe, on a branche et configure un vrai serveur physique avec un switch, puis installe Proxmox dessus. J'y ai cree plusieurs machines virtuelles a partir d'un template Windows Server 2019 (serveur de fichiers avec partages SMB, Active Directory et DNS), un serveur web Linux et une VM pour les tests et les sauvegardes.
